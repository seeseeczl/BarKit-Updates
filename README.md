# BarKit Updates

This public repository is the binary distribution channel for
[BarKit](https://github.com/seeseeczl/BarKit).

It contains only:

- the stable Sparkle `appcast.xml`;
- Developer ID signed and Apple-notarized release ZIP files;
- release metadata needed by installed BarKit apps.

Source code, Apple credentials, GitHub tokens, notarization secrets, and the
Sparkle private signing key are not stored here.

The first updater-enabled BarKit release must be installed manually once.
Later versions can be updated from BarKit's menu or Settings.
